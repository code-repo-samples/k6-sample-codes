#lean K6

/**
 * =============================================================================
 * High-Throughput k6 Performance Testing Framework  --  LEAN EDITION
 * =============================================================================
 *
 * Same report as the original (overall, per-phase, per-page, status
 * distribution, cache/backend breakdown, native metrics), but built so one
 * load generator (e.g. GCP c3-standard-8) can push far more TPS.
 *
 * WHAT CHANGED VS THE ORIGINAL, AND WHY
 * -------------------------------------
 *
 * 1. Per-request work is minimal.
 *      Hot path (every request):   pick URL -> HTTP call -> 1 status-class
 *                                  counter -> 1 transaction counter.
 *      Hit/miss + backend/cache indicator headers are recorded on a SAMPLE
 *      of responses (auto: ~CACHE.samplesPerSecCap samples/sec/generator),
 *      using direct O(1) header lookups instead of scanning + lowercasing
 *      every header key several times per request.
 *
 * 2. Static header detail moves to a low-rate PROBE scenario.
 *      ETag / Vary / Cache-Control (+ directives, max-age) / Age values are
 *      constant per page, so they are captured by a 1-5 TPS `header_probe`
 *      scenario instead of on every request. Nothing is lost in the report.
 *
 * 3. Fewer redundant Trend series (Trends keep EVERY sample in memory).
 *      Kept:    ALL native k6 timing metrics per phase (blocked, connecting,
 *               tls, sending, waiting, receiving, iteration_duration),
 *               plus http_req_duration overall / per phase / per phase+page.
 *      Dropped: only the per-page-across-phases duration trend, which the
 *               report never displayed.
 *
 * 4. VU sizing fixed.
 *      expectedLatencySec is now a realistic default (measure yours!), and
 *      every phase has a short gracefulStop. k6's default 30s gracefulStop
 *      made back-to-back phases stack their VU pools (a 1K->5K->10K->20K
 *      ramp would initialise ~10.8K VUs up front).
 *
 * RUN-TIME FLAGS  (all optional; pass with  k6 run -e NAME=value ...)
 * ---------------------------------------------------------------
 *   RUN_PROFILE       smoke | load | stress | spike | endurance  [smoke]
 *                      picks the whole load pattern. The pattern's shape
 *                      (TPS levels, step/spike count, durations) is a plain
 *                      array literal in section 0c near the top of the
 *                      script -- edit it there, not via extra CLI flags.
 *   TEST_TYPE          label shown in the report            [= RUN_PROFILE]
 *   PHASES_JSON        advanced escape hatch: JSON array that fully replaces
 *                      the active profile's phases -- for a one-off custom
 *                      shape without editing the file; not part of normal use
 *   DURATION_DETAIL   phase_url | phase | summary   [profile's default]
 *                      controls how many duplicate http_req_duration
 *                      Trends are kept in memory -- the endurance profile
 *                      already defaults this to "summary"; override any
 *                      profile explicitly if you need to
 *   REPORT_NAME              base name of the report files      [k6-report]
 *   REPORT_DIR               folder to write reports into       [cwd]
 *   REPORT_APPEND_MACHINE_ID append -<machine> to file names    [true]
 *   K6_MACHINE_ID            id of this generator               [hostname]
 *       -> files: <REPORT_DIR>/<REPORT_NAME>-<machine>.html / .json
 *   NETWORK_METRICS          all | core | off                   [all]
 *       all  = blocked, connecting, tls, sending, waiting, receiving
 *              + iteration_duration, per phase
 *       core = blocked + waiting per phase (lowest memory)
 *       off  = none per phase (k6 still records them globally)
 *   ACCEPT_ENCODING          value for Accept-Encoding header   [gzip]
 *                            use "none" to send no header
 *   BASIC_AUTH_USER / BASIC_AUTH_PASS
 *                            shared credentials; a page opts in with
 *                            auth: true (or has its own auth: {...})
 *   PRE_ALLOCATED_VUS / MAX_VUS
 *                            pin VUs for EVERY phase
 *   PHASE_VUS                JSON, per-phase pin, e.g.
 *                            '{"steady_10000tps":{"pre":1500,"max":2500}}'
 *   EXPECTED_LATENCY_SEC     latency used by the VU formula     [0.1]
 *   MAX_VU_MULTIPLIER        maxVUs = preAllocated x this       [2]
 *   GRACEFUL_STOP            per-phase gracefulStop             [5s]
 *   CACHE_SAMPLE_RATE        0..1, overrides the automatic rate
 *   CACHE_SAMPLES_PER_SEC    cap used by the automatic rate     [1000]
 *   PROBE_TPS                header_probe rate, 0 disables      [2]
 *   VU precedence: phase config > PHASE_VUS > PRE_ALLOCATED_VUS/MAX_VUS
 *                  > formula (TPS x EXPECTED_LATENCY_SEC).
 *
 * RUN PROFILES  (same script, one flag picks the pattern)
 * -------------------------------------------------------
 * Calibrate on ONE VM first with the stress profile. Measure real p95
 * latency and set EXPECTED_LATENCY_SEC from it before the endurance run;
 * set K6_MACHINE_ID uniquely per VM when running distributed, and keep
 * REPORT_NAME the same across machines so merge-report.js can find them.
 * To change TPS levels, step/spike counts, or any duration for a profile,
 * edit its array in section 0c -- that's the only place these live.
 *
 * 1) LOAD TEST, 1h, single steady level:
 *    k6 run script.js -e RUN_PROFILE=load
 *
 * 2) STRESS TEST, 1h, stepped levels to find the breaking point:
 *    k6 run script.js -e RUN_PROFILE=stress
 *    (default array: 6 steps x 10m, 5k->30k tps; stop trusting results past
 *    the step where error% or dropped_iterations starts climbing -- that's
 *    your per-VM ceiling, and tells you how many VMs 20k actually needs)
 *
 * 3) SPIKE TEST, ~2h total, sharp bursts off a baseline:
 *    k6 run script.js -e RUN_PROFILE=spike
 *    (default array: 3 baseline/spike cycles + a final recovery window;
 *    preAllocatedVUs/maxVUs are hardcoded per phase in section 0c -- replace
 *    the placeholder numbers there with real ones from a prior stress-test
 *    calibration so k6 isn't scrambling to allocate VUs mid-spike)
 *
 * 4) ENDURANCE TEST, 6h, steady 20k tps:
 *    k6 run script.js -e RUN_PROFILE=endurance
 *    (DURATION_DETAIL=summary and NETWORK_METRICS=off are already the
 *    endurance profile's defaults -- no need to pass them. preAllocatedVUs/
 *    maxVUs for the endurance_steady phase are hardcoded in section 0c --
 *    replace that placeholder pair with the real number from calibration
 *    before the actual 6h run)
 *    Run under tmux/systemd/nohup, not a foreground SSH session. Confirm VM
 *    RAM/CPU headroom from the stress-test calibration before committing to
 *    the full 6h.
 *
 * SCALABILITY
 * -----------
 * No per-request arrays, logging, body retention or report objects.
 * Reporting is O(phases x URLs), not O(requests). DURATION_DETAIL controls
 * how many copies of http_req_duration are kept in memory across the run --
 * the dominant memory cost on a long, high-TPS soak (see CONFIG comment).
 *
 * NOTE ON PERCENTILES
 * -------------------
 * Percentiles from separate generators cannot be merged exactly. Merge
 * counters exactly; treat merged p95/p99 as approximate.
 *
 * =============================================================================
 */

// =============================================================================
// 0b. FLAG HELPERS  (k6 run -e NAME=value ...)
// =============================================================================

function envStr(name, dflt) {
    const v = __ENV[name];
    return (v !== undefined && v !== '') ? v : dflt;
}

function envNum(name, dflt) {
    const v = __ENV[name];
    if (v === undefined || v === '') return dflt;
    const n = Number(v);
    if (isNaN(n)) throw new Error(`${name} must be a number, got "${v}"`);
    return n;
}

function envJson(name, dflt) {
    const v = __ENV[name];
    if (v === undefined || v === '') return dflt;
    try { return JSON.parse(v); }
    catch (e) { throw new Error(`${name} must be valid JSON: ${e.message}`); }
}

// Safe for use inside file names.
function safeName(s) {
    return String(s).replace(/[^A-Za-z0-9._-]/g, '_');
}

function statusClass(status) {
    if (status === 0) return 'err';
    if (status < 300) return '2xx';
    if (status < 400) return '3xx';
    if (status < 500) return '4xx';
    return '5xx';
}

const CACHE_STRATEGY = {
    'aws-cloudfront': 'header',
    'cdn-header': 'header',
    // GCP Cloud CDN / GCLB has no explicit X-Cache-style header, but always
    // returns `Age`. Age > 0 => served from cache; missing/0 => origin.
    'gcp-cdn': 'gcp-age',
    'direct-bucket': 'not-applicable',
};

// =============================================================================
// 3b. HEADER KEY HELPERS
// =============================================================================
//
// k6 exposes response header keys in Go's canonical form
// ("ETag" -> "Etag", "CF-Cache-Status" -> "Cf-Cache-Status",
// "response_sent_by_backend" -> "Response_sent_by_backend").
// The hot path therefore uses direct property lookups on the canonical key
// (O(1)) instead of scanning every header and lowercasing it.
//
// The low-rate probe still uses a full case-insensitive scan and logs a
// one-time warning if a header exists but the canonical key would have
// missed it, so a casing surprise can never silently zero out a metric.
// =============================================================================

function canonKey(name) {
    return String(name)
        .split('-')
        .map((p) => p.charAt(0).toUpperCase() + p.slice(1).toLowerCase())
        .join('-');
}

const HK = {
    age: canonKey(CONFIG.cacheHeaders.ageHeader),
    backend: canonKey(CONFIG.cacheHeaders.backendHeader),
    cacheResp: canonKey(CONFIG.cacheHeaders.cacheResponseHeader),
    status: CONFIG.cacheHeaders.statusHeaders.map(canonKey),
};

function getHeaderCI(headers, name) {

    if (!headers || !name) {
        return undefined;
    }

    const lower = name.toLowerCase();

    for (const key in headers) {
        if (key.toLowerCase() === lower) {
            return headers[key];
        }
    }

    return undefined;
}

    CONFIG.phases.reduce((m, p) => Math.max(m, p.targetTPS), 0);

const CACHE_SAMPLE_RATE =
    (typeof CONFIG.cache.sampleRate === 'number')
        ? Math.max(0, Math.min(1, CONFIG.cache.sampleRate))
        : (MAX_TARGET_TPS > 0
            ? Math.min(1, CONFIG.cache.samplesPerSecCap / MAX_TARGET_TPS)
            : 1);

// 4. URL TABLE  (built once at init; everything per-request is precomputed)

// Request headers are built ONCE here (never per request).
const BASE_HEADERS = {};

if (String(CONFIG.acceptEncoding).toLowerCase() !== 'none') {
    BASE_HEADERS['Accept-Encoding'] = CONFIG.acceptEncoding;
}

Object.assign(BASE_HEADERS, CONFIG.requestHeaders);

// Basic-auth header per distinct credential pair, computed once.
const _authHeaderCache = {};

function basicAuthHeader(username, password) {

    const key = `${username}\u0000${password}`;

    if (!_authHeaderCache[key]) {
        _authHeaderCache[key] =
            `Basic ${encoding.b64encode(`${username}:${password}`)}`;
    }

    return _authHeaderCache[key];
}

function resolveAuthHeader(urlConf) {

    if (!urlConf.auth) {
        return null;
    }

    if (urlConf.auth === true) {

        const shared = CONFIG.sharedAuth;

        if (!shared.username) {
            throw new Error(
                `Page "${urlConf.id}" has auth: true but BASIC_AUTH_USER / ` +
                `BASIC_AUTH_PASS were not provided.`
            );
        }

        return basicAuthHeader(shared.username, shared.password);
    }

    if (urlConf.auth.username) {
        return basicAuthHeader(urlConf.auth.username, urlConf.auth.password || '');
    }

    return null;
}

const URL_TABLE = (function buildUrlTable(urls) {

    const total = urls.reduce((sum, u) => sum + u.weight, 0);

    let cumulative = 0;

    return urls.map((u) => {

        cumulative += u.weight;

        const headers = Object.assign({}, BASE_HEADERS, u.headers || {});
        const authHeader = resolveAuthHeader(u);

        if (authHeader) {
            headers['Authorization'] = authHeader;
        }

        // The probe sends the SAME headers so it observes the same cache variant.
        const params = { tags: { page: u.id }, responseType: 'none', headers };
        const probeParams = { tags: { page: PROBE_PAGE_TAG }, responseType: 'none', headers };

        const classTags = {};
        STATUS_CLASSES.forEach((cls) => {
            classTags[cls] = { page: u.id, class: cls };
        });

        return {
            ...u,
            cumWeight: cumulative / total,
            method: u.method || 'GET',
            body: u.body || null,
            reqUrl: u.url,
            params,
            probeParams,
            tagPage: { page: u.id },
            classTags,
            cacheStrategy: CACHE_STRATEGY[u.provider] || 'header',
        };
    });

})(CONFIG.urls);

function pickUrl() {
    const r = Math.random();
    for (let i = 0; i < URL_TABLE.length; i++) {
        if (r <= URL_TABLE[i].cumWeight) {
            return URL_TABLE[i];
        }
    }
    return URL_TABLE[URL_TABLE.length - 1];
}

// 6. DURATION PARSING
// =============================================================================

function parseDurationToSeconds(dur) {
    const re = /(\d+)\s*(h|m|s)/g;
    let match, totalSeconds = 0, found = false;

    while ((match = re.exec(dur)) !== null) {
        found = true;
        const value = parseInt(match[1], 10);
        const unit = match[2];

        if (unit === 'h') totalSeconds += value * 3600;
        else if (unit === 'm') totalSeconds += value * 60;
        else totalSeconds += value;
    }

    if (!found) throw new Error(`Cannot parse duration: ${dur}`);
    return totalSeconds;
}

// =============================================================================
// 7. SCENARIOS
// =============================================================================
//
// One constant-arrival-rate scenario per phase, scheduled back-to-back,
// plus (optionally) one low-rate header_probe scenario spanning the test.
// =============================================================================

const VU_PLAN = [];

// Precedence: phase config > PHASE_VUS flag > PRE_ALLOCATED_VUS / MAX_VUS
// flags > formula (TPS x expectedLatencySec).
function resolveVus(phase, config) {

    const perPhase = config.vus.perPhase[phase.name] || {};

    const pinned =
        !!(phase.preAllocatedVUs || perPhase.pre || config.vus.preAllocated);

    const pre =
        phase.preAllocatedVUs ||
        perPhase.pre ||
        config.vus.preAllocated ||
        Math.max(10, Math.ceil(phase.targetTPS * config.expectedLatencySec));

    const max =
        phase.maxVUs ||
        perPhase.max ||
        config.vus.max ||
        Math.ceil(pre * config.maxVuMultiplier);

    return {
        pre,
        max: Math.max(max, pre),
        source: pinned ? 'pinned' : 'formula',
    };
}

function buildScenarios(config) {
    const scenarios = {};
    let cumulativeStartSeconds = 0;

    config.phases.forEach((phase) => {
        const durationSeconds =
            parseDurationToSeconds(phase.duration);

        const vus = resolveVus(phase, config);
        const preAllocatedVUs = vus.pre;
        const maxVUs = vus.max;

        VU_PLAN.push({
            phase: phase.name,
            targetTPS: phase.targetTPS,
            preAllocatedVUs,
            maxVUs,
            source: vus.source,
        });

        scenarios[phase.name] = {
            executor: 'constant-arrival-rate',
            rate: phase.targetTPS,
            timeUnit: '1s',
            duration: phase.duration,
            preAllocatedVUs,
            maxVUs,
            gracefulStop: config.gracefulStop,
            startTime: `${cumulativeStartSeconds}s`,
            exec: 'runTest',
        };

        cumulativeStartSeconds += durationSeconds;
    });

    if (config.cache.probeTps > 0 && cumulativeStartSeconds > 0) {
        scenarios[PROBE_SCENARIO] = {
            executor: 'constant-arrival-rate',
            rate: config.cache.probeTps,
            timeUnit: '1s',
            duration: `${cumulativeStartSeconds}s`,
            preAllocatedVUs: 2,
            maxVUs: 10,
            gracefulStop: '5s',
            startTime: '0s',
            exec: 'runProbe',
        };
    }

    return scenarios;
}

// =============================================================================
// 9. THRESHOLDS  (always-true; they only register bounded submetric series)
// =============================================================================
//
// Series count = phases x URLs x few metrics, NOT requests.
//
// Trend submetrics are the expensive ones (each keeps every sample). Only the
// ones the report displays are registered.
// =============================================================================

function buildThresholds(config) {

    const th = {};

    const urls = config.urls.map((u) => u.id);
    const phases = config.phases.map((p) => p.name);

    // Probe traffic is excluded from phase metrics by its own scenario tag;
    // this series lets the summary subtract probe requests from http_reqs.
    th[`http_reqs{scenario:${PROBE_SCENARIO}}`] = ['count>=0'];

    // ---------------------------------------------------------------------------
    // URL-level metrics (counters / rates only -- no Trend copies)
    // ---------------------------------------------------------------------------

    urls.forEach((url) => {

        th[urlTag('http_reqs', url)] = ['count>=0'];
        th[urlTag('http_req_failed', url)] = ['rate>=0'];
        th[urlTag('transaction_count', url)] = ['count>=0'];

        th[urlTag('cache_hit_count', url)] = ['count>=0'];
        th[urlTag('cache_miss_count', url)] = ['count>=0'];
        th[urlTag('cache_unknown_count', url)] = ['count>=0'];
        th[urlTag('cache_not_observable_count', url)] = ['count>=0'];
        th[urlTag('cache_not_applicable_count', url)] = ['count>=0'];
        th[urlTag('backend_response_count', url)] = ['count>=0'];
        th[urlTag('cache_response_count', url)] = ['count>=0'];

        // Probe-sourced series (low volume, so a Trend here is harmless).
        th[urlTag('probe_count', url)] = ['count>=0'];
        th[urlTag('age_present_count', url)] = ['count>=0'];
        th[urlTag('cache_age', url)] = ['avg>=0'];
        th[urlTag('cache_control_present_count', url)] = ['count>=0'];
        th[urlTag('etag_present_count', url)] = ['count>=0'];
        th[urlTag('vary_present_count', url)] = ['count>=0'];
        th[urlTag('cache_control_max_age', url)] = ['avg>=0'];

        CACHE_CONTROL_DIRECTIVES.forEach((dir) => {
            th[urlDirectiveTag('cache_control_directive_count', url, dir)] =
                ['count>=0'];
        });

        STATUS_CLASSES.forEach((cls) => {
            th[urlClassTag('status_class_count', url, cls)] = ['count>=0'];
        });
    });

    // ---------------------------------------------------------------------------
    // Phase-level metrics
    // ---------------------------------------------------------------------------

    phases.forEach((phase) => {

        th[phaseTag('http_reqs', phase)] = ['count>=0'];
        th[phaseTag('transaction_count', phase)] = ['count>=0'];
        if (TRACK_PHASE_DURATION) {
            th[phaseTag('http_req_duration', phase)] = ['p(99)>=0'];
        }
        th[phaseTag('http_req_failed', phase)] = ['rate>=0'];
        th[phaseTag('iterations', phase)] = ['count>=0'];
        th[phaseTag('dropped_iterations', phase)] = ['count>=0'];
        if (TRACK_ITERATION_DURATION) {
            th[phaseTag('iteration_duration', phase)] = ['p(99)>=0'];
        }
        th[phaseTag('data_sent', phase)] = ['count>=0'];
        th[phaseTag('data_received', phase)] = ['count>=0'];

        NETWORK_TREND_METRICS.forEach((m) => {
            th[phaseTag(m.key, phase)] = ['p(99)>=0'];
        });

        STATUS_CLASSES.forEach((cls) => {
            th[phaseClassTag('status_class_count', phase, cls)] = ['count>=0'];
        });

        // -------------------------------------------------------------------------
        // PHASE + URL metrics
        // -------------------------------------------------------------------------

        urls.forEach((url) => {

            th[phaseUrlTag('http_reqs', phase, url)] = ['count>=0'];
            th[phaseUrlTag('transaction_count', phase, url)] = ['count>=0'];
            if (TRACK_PHASE_URL_DURATION) {
                th[phaseUrlTag('http_req_duration', phase, url)] = ['p(99)>=0'];
            }

            STATUS_CLASSES.forEach((cls) => {
                th[phaseUrlClassTag('status_class_count', phase, url, cls)] =
                    ['count>=0'];
            });
        });
    });

    return th;
}

// =============================================================================
// 11. TEST FUNCTION  (executes once per arrival -- keep it tiny)
// =============================================================================

export function runTest() {

    const u = pickUrl();

    // One transaction per iteration, regardless of redirect hops.
    transactionCount.add(1, u.tagPage);

    const res = http.request(u.method, u.reqUrl, u.body, u.params);

    statusClassCount.add(1, u.classTags[statusClass(res.status)]);

    if (CACHE_SAMPLE_RATE >= 1 || Math.random() < CACHE_SAMPLE_RATE) {
        recordCacheSampled(res, u);
    }
}

// =============================================================================
// 12. SAMPLED CACHE / BACKEND CLASSIFICATION  (direct O(1) header lookups)
// =============================================================================

function recordCacheSampled(res, u) {

    const strategy = u.cacheStrategy;

    if (strategy === 'not-applicable') {
        cacheNotApplicableCount.add(1, u.tagPage);
        return;
    }

    if (strategy === 'not-observable') {
        cacheNotObservableCount.add(1, u.tagPage);
        return;
    }

    const headers = res.headers;

    if (strategy === 'gcp-age') {

        // Age > 0 => served from cache; Age missing => cannot tell.
        const raw = headers[HK.age];
        const ageNum = raw !== undefined ? parseFloat(raw) : NaN;

        if (ageNum === ageNum) {
            if (ageNum > 0) {
                cacheHitCount.add(1, u.tagPage);
            } else {
                cacheMissCount.add(1, u.tagPage);
            }
        } else {
            cacheUnknownCount.add(1, u.tagPage);
        }

    } else {

        // Header-based CDN classification (first matching header wins).
        let classified = false;

        for (let i = 0; i < HK.status.length; i++) {

            const value = headers[HK.status[i]];

            if (value === undefined) {
                continue;
            }

            const v = String(value).toLowerCase();

            if (v.includes('hit')) {
                cacheHitCount.add(1, u.tagPage);
                classified = true;
                break;
            }

            if (v.includes('miss')) {
                cacheMissCount.add(1, u.tagPage);
                classified = true;
                break;
            }
        }

        if (!classified) {
            cacheUnknownCount.add(1, u.tagPage);
        }
    }

    // Custom per-response indicators (these DO vary per response).
    const backendValue = headers[HK.backend];

    if (backendValue !== undefined && String(backendValue).toLowerCase() === 'true') {
        backendResponseCount.add(1, u.tagPage);
    }

    const cacheRespValue = headers[HK.cacheResp];

    if (cacheRespValue !== undefined && String(cacheRespValue).toLowerCase() === 'true') {
        cacheResponseCount.add(1, u.tagPage);
    }
}

// =============================================================================
// 13. HEADER PROBE  (low rate; full detail; case-insensitive scan)
// =============================================================================
//
// Runs at CONFIG.cache.probeTps (default 2/s), round-robin over the pages.
// Captures the per-page header details that are static by nature:
// Age (value range), Cache-Control (+directives, max-age), ETag, Vary.
// =============================================================================

const _warnedHeaders = {};

function warnIfCanonicalMisses(headers, configuredName, canonical) {

    if (_warnedHeaders[configuredName]) {
        return;
    }

    if (getHeaderCI(headers, configuredName) !== undefined &&
        headers[canonical] === undefined) {

        _warnedHeaders[configuredName] = true;

        console.warn(
            `[lean-cache] header "${configuredName}" is present but not under ` +
            `key "${canonical}" -- hot-path hit/miss will under-count. ` +
            `Check header key casing for this k6 version.`
        );
    }
}

export function runProbe() {

    const u = URL_TABLE[
        exec.scenario.iterationInTest % URL_TABLE.length
    ];

    if (u.cacheStrategy === 'not-applicable' ||
        u.cacheStrategy === 'not-observable') {
        return;
    }

    const res = http.request(u.method, u.reqUrl, u.body, u.probeParams);

    recordProbe(res, u);
}

function recordProbe(res, u) {

    const id = u.id;
    const cfg = CONFIG.cacheHeaders;
    const headers = res.headers;
    const tags = u.tagPage;

    probeCount.add(1, tags);

    // Safety net: confirm the hot-path canonical keys really match.
    warnIfCanonicalMisses(headers, cfg.ageHeader, HK.age);
    warnIfCanonicalMisses(headers, cfg.backendHeader, HK.backend);
    warnIfCanonicalMisses(headers, cfg.cacheResponseHeader, HK.cacheResp);
    cfg.statusHeaders.forEach((name, i) =>
        warnIfCanonicalMisses(headers, name, HK.status[i]));

    // Age
    const ageValueRaw = getHeaderCI(headers, cfg.ageHeader);
    const ageNum = ageValueRaw !== undefined ? parseFloat(ageValueRaw) : NaN;

    if (!isNaN(ageNum)) {
        agePresentCount.add(1, tags);
        cacheAge.add(ageNum, tags);
    }

    // ETag
    const etagValue = getHeaderCI(headers, cfg.etagHeader);

    if (etagValue !== undefined && String(etagValue).length > 0) {
        etagPresentCount.add(1, tags);
    }

    // Vary
    const varyValue = getHeaderCI(headers, cfg.varyHeader);

    if (varyValue !== undefined && String(varyValue).length > 0) {
        varyPresentCount.add(1, tags);
    }

    // Cache-Control directives + max-age
    const cacheControlValue = getHeaderCI(headers, cfg.cacheControlHeader);

    if (cacheControlValue !== undefined) {

        cacheControlPresentCount.add(1, tags);

        String(cacheControlValue)
            .toLowerCase()
            .split(',')
            .map((d) => d.trim())
            .filter(Boolean)
            .forEach((directive) => {

                const [dirName, dirVal] = directive.split('=');

                if (CACHE_CONTROL_DIRECTIVES.includes(dirName)) {
                    cacheControlDirectiveCount.add(1, { page: id, directive: dirName });
                }

                if (dirName === 'max-age' && dirVal !== undefined) {
                    const maxAgeNum = parseFloat(dirVal);
                    if (!isNaN(maxAgeNum)) cacheControlMaxAge.add(maxAgeNum, tags);
                }
            });
    }
}

function metric(data, name) {

    return (
        data.metrics &&
        data.metrics[name]
    ) || null;
}

function trendStat(m, stat, fallback = 0) {
    return (m && m.values && m.values[stat] !== undefined) ? m.values[stat] : fallback;
}

function counterCount(m, fallback = 0) {
    return (m && m.values && m.values.count !== undefined) ? m.values.count : fallback;
}

function rateValue(m, fallback = 0) {
    return (m && m.values && m.values.rate !== undefined) ? m.values.rate : fallback;
}

function gaugeMax(m, fallback = 0) {
    return (m && m.values && m.values.max !== undefined) ? m.values.max : fallback;
}

function pct(part, whole) {
    return whole > 0 ? (part / whole) * 100 : 0;
}

function fmt(n, decimals = 2) {
    if (n === null || n === undefined || isNaN(n)) return 'n/a';
    return Number(n).toFixed(decimals);
}

function esc(str) {
    return String(str)
        .replace(/&/g, '&amp;')
        .replace(/</g, '&lt;')
        .replace(/>/g, '&gt;')
        .replace(/"/g, '&quot;')
        .replace(/'/g, '&#039;');
}

function fmtBytes(n) {
    if (n === null || n === undefined || isNaN(n)) return 'n/a';
    const num = Number(n);
    if (num < 1024) return `${num.toFixed(0)} B`;
    if (num < 1024 * 1024) return `${(num / 1024).toFixed(2)} KB`;
    return `${(num / (1024 * 1024)).toFixed(2)} MB`;
}

// =============================================================================
// 15. BUILD PAGE METRICS FOR A SPECIFIC PHASE
// =============================================================================
//
// THIS is the main reporting change.
//
// Every page is now explicitly scoped to:
//
//     scenario = phase
//     url      = page
//
// Therefore:
//
// Phase 1000 TPS
//   Homepage response metrics
//   FAQ response metrics
//   ContactUs response metrics
//
// Phase 5000 TPS
//   Homepage response metrics
//   FAQ response metrics
//   ContactUs response metrics
//
// etc.
// =============================================================================

function buildPhasePageRow(
    data,
    phase,
    urlConf
) {

    const phaseName =
        phase.name;

    const id =
        urlConf.id;

    // ---------------------------------------------------------------------------
    // Phase + URL transaction count (logical requests, excl. redirect hops)
    // ---------------------------------------------------------------------------

    const transactions =
        counterCount(
            metric(
                data,
                phaseUrlTag(
                    'transaction_count',
                    phaseName,
                    id
                )
            )
        );

    // ---------------------------------------------------------------------------
    // Phase + URL request count (raw HTTP requests, incl. redirect hops)
    // ---------------------------------------------------------------------------

    const reqs =
        counterCount(
            metric(
                data,
                phaseUrlTag(
                    'http_reqs',
                    phaseName,
                    id
                )
            )
        );

    // ---------------------------------------------------------------------------
    // Phase + URL response time
    // ---------------------------------------------------------------------------

    const durationM =
        metric(
            data,
            phaseUrlTag(
                'http_req_duration',
                phaseName,
                id
            )
        );

    // ---------------------------------------------------------------------------
    // Phase + URL status classes
    // ---------------------------------------------------------------------------

    const classCounts = {};

    STATUS_CLASSES.forEach((cls) => {

        classCounts[cls] =
            counterCount(
                metric(
                    data,
                    phaseUrlClassTag(
                        'status_class_count',
                        phaseName,
                        id,
                        cls
                    )
                )
            );
    });

    const failed =
        classCounts['4xx'] +
        classCounts['5xx'] +
        classCounts['err'];

    const passed =
        Math.max(
            0,
            reqs - failed
        );

    const errorPct =
        pct(
            failed,
            reqs
        );

    return {

        id,

        name:
            urlConf.name || id,

        url:
            urlConf.url,

        authEnabled:
            !!(urlConf.auth === true || (urlConf.auth && urlConf.auth.username)),

        transactions,

        count:
            reqs,

        avg:
            trendStat(
                durationM,
                'avg',
                null
            ),

        min:
            trendStat(
                durationM,
                'min',
                null
            ),

        p90:
            trendStat(
                durationM,
                'p(90)',
                null
            ),

        p95:
            trendStat(
                durationM,
                'p(95)',
                null
            ),

        p99:
            trendStat(
                durationM,
                'p(99)',
                null
            ),

        max:
            trendStat(
                durationM,
                'max',
                null
            ),

        passed,

        failed,

        errorPct,

        classCounts,

        status:
            errorPct <=
                CONFIG.reporting.maxErrorRatePct
                ? 'PASS'
                : 'FAIL',
    };
}

// =============================================================================
// 16. BUILD PHASE ROW
// =============================================================================
//
// Each phase contains its own pages[] collection.
//
// This gives the report hierarchy:
//
// phase
//   -> TPS
//   -> phase status
//   -> pages
//        -> Homepage
//        -> FAQ
//        -> ContactUs
// =============================================================================

function buildPhaseRow(
    data,
    phase
) {

    const name =
        phase.name;

    // ---------------------------------------------------------------------------
    // Phase transaction count (logical) vs request count (raw, incl. redirects)
    // ---------------------------------------------------------------------------

    const transactions =
        counterCount(
            metric(
                data,
                phaseTag(
                    'transaction_count',
                    name
                )
            )
        );

    const reqs =
        counterCount(
            metric(
                data,
                phaseTag(
                    'http_reqs',
                    name
                )
            )
        );

    // ---------------------------------------------------------------------------
    // Phase response time
    //
    // Kept for overall phase-level context.
    // Page-level values are shown below it.
    // ---------------------------------------------------------------------------

    const durationM =
        metric(
            data,
            phaseTag(
                'http_req_duration',
                name
            )
        );

    // ---------------------------------------------------------------------------
    // Phase status classes
    // ---------------------------------------------------------------------------

    const classCounts = {};

    STATUS_CLASSES.forEach((cls) => {

        classCounts[cls] =
            counterCount(
                metric(
                    data,
                    phaseClassTag(
                        'status_class_count',
                        name,
                        cls
                    )
                )
            );
    });

    const failed =
        classCounts['4xx'] +
        classCounts['5xx'] +
        classCounts['err'];

    const passed =
        Math.max(
            0,
            reqs - failed
        );

    const errorPct =
        pct(
            failed,
            reqs
        );

    // ---------------------------------------------------------------------------
    // Phase duration / actual TPS
    //
    // Actual TPS is based on transactions (logical requests), not raw
    // http_reqs, so it isn't inflated by redirect hops.
    // ---------------------------------------------------------------------------

    const durationSeconds =
        parseDurationToSeconds(
            phase.duration
        );

    const actualTps =
        durationSeconds > 0
            ? transactions / durationSeconds
            : 0;

    // ---------------------------------------------------------------------------
    // Dropped iterations
    //
    // Tracked for visibility only. Per requirements, dropped iterations do
    // NOT cause a phase or the overall run to fail -- see `status` below,
    // which intentionally omits dropOk from the pass/fail decision.
    // ---------------------------------------------------------------------------

    const dropped =
        counterCount(
            metric(
                data,
                phaseTag(
                    'dropped_iterations',
                    name
                )
            )
        );

    // ---------------------------------------------------------------------------
    // TPS achievement
    // ---------------------------------------------------------------------------

    const tpsAchievementPct =
        pct(
            actualTps,
            phase.targetTPS
        );

    const tpsOk =
        tpsAchievementPct >=
        CONFIG.reporting.minTpsAchievementPct;

    const errOk =
        errorPct <=
        CONFIG.reporting.maxErrorRatePct;

    // Informational only -- intentionally NOT part of `status` below.
    const dropOk =
        dropped === 0;

    // ---------------------------------------------------------------------------
    // PAGE METRICS INSIDE THIS PHASE
    // ---------------------------------------------------------------------------

    const pages =
        CONFIG.urls.map(
            (urlConf) =>
                buildPhasePageRow(
                    data,
                    phase,
                    urlConf
                )
        );

    const networkMetrics = buildPhaseNetworkMetrics(data, name);

    return {
        phase: name,
        targetTps: phase.targetTPS,
        transactions,
        actualTps,
        tpsAchievementPct,
        duration: phase.duration,
        avg: trendStat(durationM, 'avg', null),
        min: trendStat(durationM, 'min', null),
        p90: trendStat(durationM, 'p(90)', null),
        p95: trendStat(durationM, 'p(95)', null),
        p99: trendStat(durationM, 'p(99)', null),
        max: trendStat(durationM, 'max', null),
        count: reqs,
        passed,
        failed,
        errorPct,
        classCounts,
        dropped,
        tpsOk,
        errOk,
        dropOk,
        // Dropped iterations deliberately excluded from pass/fail.
        status: tpsOk && errOk ? 'PASS' : 'FAIL',
        pages,
        networkMetrics,
    };
}

// =============================================================================
// 16b. NATIVE NETWORK METRICS FOR A PHASE
// =============================================================================
//
// Pulls back out the native k6 metrics that were already registered as
// phase-scoped submetrics in buildThresholds(). No new metric objects are
// created here -- this only reads data k6 was already collecting.
// =============================================================================

function buildPhaseNetworkMetrics(
    data,
    phaseName
) {

    const trends =
        NETWORK_TREND_METRICS.map((m) => {

            const met =
                metric(
                    data,
                    phaseTag(
                        m.key,
                        phaseName
                    )
                );

            return {

                key:
                    m.key,

                label:
                    m.label,

                avg:
                    trendStat(met, 'avg'),

                min:
                    trendStat(met, 'min'),

                p90:
                    trendStat(met, 'p(90)'),

                p95:
                    trendStat(met, 'p(95)'),

                p99:
                    trendStat(met, 'p(99)'),

                max:
                    trendStat(met, 'max'),
            };
        });

    const dataSentBytes =
        counterCount(
            metric(
                data,
                phaseTag('data_sent', phaseName)
            )
        );

    const dataReceivedBytes =
        counterCount(
            metric(
                data,
                phaseTag('data_received', phaseName)
            )
        );

    const iterDurM =
        metric(
            data,
            phaseTag('iteration_duration', phaseName)
        );

    const iterationDuration = !TRACK_ITERATION_DURATION ? null : {

        avg:
            trendStat(iterDurM, 'avg'),

        min:
            trendStat(iterDurM, 'min'),

        p90:
            trendStat(iterDurM, 'p(90)'),

        p95:
            trendStat(iterDurM, 'p(95)'),

        p99:
            trendStat(iterDurM, 'p(99)'),

        max:
            trendStat(iterDurM, 'max'),
    };

    const httpReqFailedM =
        metric(
            data,
            phaseTag('http_req_failed', phaseName)
        );

    const httpReqFailedPct =
        rateValue(httpReqFailedM) * 100;

    return {

        trends,

        dataSentBytes,

        dataReceivedBytes,

        iterationDuration,

        httpReqFailedPct,
    };
}

// =============================================================================
// 17. CACHE REPORT
// =============================================================================

function buildCacheRow(data, urlConf) {
    const id = urlConf.id;
    const strategy = CACHE_STRATEGY[urlConf.provider] || 'header';

    if (strategy === 'not-applicable') {
        return { id, name: urlConf.name || id, url: urlConf.url, strategy, note: 'No CDN in front of this URL -- not applicable.' };
    }

    if (strategy === 'not-observable') {
        return { id, name: urlConf.name || id, url: urlConf.url, strategy, note: 'GCP Cloud CDN does not expose cache status to the client. Check cache_result in Cloud Monitoring / Cloud Logging for the test time window.' };
    }

    const hit = counterCount(metric(data, urlTag('cache_hit_count', id)));
    const miss = counterCount(metric(data, urlTag('cache_miss_count', id)));
    const unknown = counterCount(metric(data, urlTag('cache_unknown_count', id)));
    const backend = counterCount(metric(data, urlTag('backend_response_count', id)));
    const cacheResp = counterCount(metric(data, urlTag('cache_response_count', id)));
    const classifiable = hit + miss;

    // Basis for presence percentages: total transactions for this page
    // across the whole run (not just classifiable hit/miss ones).
    const transactions = counterCount(metric(data, urlTag('transaction_count', id)));
    // Static-header presence (Age value / Cache-Control / ETag / Vary) comes from
    // the low-rate header_probe scenario, so its percentage basis is the number
    // of probe responses, not total transactions.
    const probeSamples = counterCount(metric(data, urlTag('probe_count', id)));

    // ---------------------------------------------------------------------------
    // Age: YES/NO + the observed value range.
    // ---------------------------------------------------------------------------

    const agePresent = counterCount(metric(data, urlTag('age_present_count', id)));
    const ageM = metric(data, urlTag('cache_age', id));

    const age = {
        sampleCount: agePresent,
        present: agePresent > 0,
        presentPct: pct(agePresent, probeSamples),
        avg: trendStat(ageM, 'avg'),
        min: trendStat(ageM, 'min'),
        max: trendStat(ageM, 'max'),
        p90: trendStat(ageM, 'p(90)'),
    };

    // ---------------------------------------------------------------------------
    // Cache-Control: YES/NO + reconstructed value.
    //
    // We can't store the raw header string itself (k6 thresholds/submetrics
    // have to be declared ahead of time, so an arbitrary runtime string
    // can't be captured as one series). Instead we reconstruct the value
    // from the bounded set of directives + max-age we DO track: any
    // directive seen on every single Cache-Control response is treated as
    // part of the "typical" value. In practice Cache-Control is static per
    // page/origin config (unlike Age, which legitimately changes per
    // request), so this reproduces the real value. If directives are
    // inconsistent across responses, that's flagged instead of guessing.
    // ---------------------------------------------------------------------------

    const cacheControlPresent = counterCount(metric(data, urlTag('cache_control_present_count', id)));
    const avgMaxAge = trendStat(metric(data, urlTag('cache_control_max_age', id)), 'avg');

    const directiveCounts = {};
    CACHE_CONTROL_DIRECTIVES.forEach((dir) => {
        directiveCounts[dir] = counterCount(metric(data, urlDirectiveTag('cache_control_directive_count', id, dir)));
    });

    const directiveSummary =
        CACHE_CONTROL_DIRECTIVES
            .map((dir) => (directiveCounts[dir] > 0 ? `${dir}:${directiveCounts[dir]}` : null))
            .filter(Boolean)
            .join(', ') || 'n/a';

    let cacheControlTypicalValue = 'n/a';
    let cacheControlConsistent = true;

    if (cacheControlPresent > 0) {

        const parts = [];

        CACHE_CONTROL_DIRECTIVES.forEach((dir) => {

            const count = directiveCounts[dir];

            if (count === 0) {
                return;
            }

            if (count < cacheControlPresent) {
                cacheControlConsistent = false;
            }

            if (dir === 'max-age') {
                parts.push(`max-age=${fmt(avgMaxAge, 0)}`);
            } else {
                parts.push(dir);
            }
        });

        cacheControlTypicalValue =
            parts.length > 0
                ? parts.join(', ')
                : 'present (no tracked directives matched)';
    }

    const cacheControl = {
        present: cacheControlPresent > 0,
        presentPct: pct(cacheControlPresent, probeSamples),
        typicalValue: cacheControlTypicalValue,
        consistent: cacheControlConsistent,
        directiveCounts,
        directiveSummary,
        avgMaxAge,
        sampleCount: cacheControlPresent,
    };

    const etagPresent = counterCount(metric(data, urlTag('etag_present_count', id)));
    const varyPresent = counterCount(metric(data, urlTag('vary_present_count', id)));

    return {
        id,
        name: urlConf.name || id,
        url: urlConf.url,
        strategy,
        hit,
        miss,
        unknown,
        hitPct: pct(hit, classifiable),
        backend,
        cacheResp,
        transactions,
        probeSamples,
        age,
        cacheControl,
        etagPresent,
        etagPct: pct(etagPresent, probeSamples),
        varyPresent,
        varyPct: pct(varyPresent, probeSamples),
    };
}

// =============================================================================
// 19. HANDLE SUMMARY
// =============================================================================
//
// Runs once after the test.
//
// All data here is already aggregated by k6.
// =============================================================================

export function handleSummary(data) {

    const durationMs =
        data.state &&
            data.state.testRunDurationMs
            ? data.state.testRunDurationMs
            : 0;

    const durationSec =
        durationMs / 1000;

    const endTime =
        new Date();

    const startTime =
        new Date(
            endTime.getTime() -
            durationMs
        );

    // ===========================================================================
    // OVERALL REQUESTS / TRANSACTIONS
    // ===========================================================================

    // Probe requests (header_probe scenario) are subtracted so the totals
    // reflect only the load phases.
    const overallReqs =
        Math.max(
            0,
            counterCount(metric(data, 'http_reqs')) -
            counterCount(metric(data, `http_reqs{scenario:${PROBE_SCENARIO}}`))
        );

    // Sum the bounded per-URL transaction counts -- same aggregation
    // pattern used for overallClassCounts below, so this stays
    // O(phases x URLs), not O(requests).
    const overallTransactions =
        CONFIG.urls.reduce(
            (sum, u) =>
                sum +
                counterCount(
                    metric(
                        data,
                        urlTag('transaction_count', u.id)
                    )
                ),
            0
        );

    const overallDurationM =
        metric(
            data,
            'http_req_duration'
        );

    // ===========================================================================
    // OVERALL STATUS CLASSES
    // ===========================================================================
    //
    // Sum the bounded URL-level class metrics.
    // This does NOT scan individual requests.
    // ===========================================================================

    const overallClassCounts = {};

    STATUS_CLASSES.forEach((cls) => {

        overallClassCounts[cls] =
            CONFIG.urls.reduce(
                (sum, u) => {

                    return sum +
                        counterCount(
                            metric(
                                data,
                                urlClassTag(
                                    'status_class_count',
                                    u.id,
                                    cls
                                )
                            )
                        );
                },
                0
            );
    });

    const overallFailed =
        overallClassCounts['4xx'] +
        overallClassCounts['5xx'] +
        overallClassCounts['err'];

    const overallPassed =
        Math.max(
            0,
            overallReqs -
            overallFailed
        );

    const overallErrorPct =
        pct(
            overallFailed,
            overallReqs
        );

    const overallDropped =
        CONFIG.phases.reduce(
            (sum, p) =>
                sum + counterCount(metric(data, phaseTag('dropped_iterations', p.name))),
            0
        );

    // ===========================================================================
    // TARGET TPS
    // ===========================================================================

    const overallTargetTps =
        CONFIG.phases.reduce(
            (max, p) =>
                Math.max(
                    max,
                    p.targetTPS
                ),
            0
        );

    // ===========================================================================
    // OVERALL ACTUAL TPS
    // ===========================================================================
    //
    // This is informational only because multiple phases can have different
    // target rates. Based on transactions (logical requests), not raw
    // http_reqs, so redirect hops don't inflate it.
    //
    // The authoritative TPS assessment is in the phase table.
    // ===========================================================================

    const overallActualTps =
        durationSec > 0
            ? overallTransactions / durationSec
            : 0;

    // ===========================================================================
    // OVERALL ACCEPTANCE
    // ===========================================================================
    //
    // Dropped iterations are intentionally excluded from the pass/fail
    // decision -- dropOk is still computed and shown, but not AND'ed in.
    // ===========================================================================

    const errOk =
        overallErrorPct <=
        CONFIG.reporting.maxErrorRatePct;

    const dropOk =
        overallDropped === 0;

    // For multi-phase tests, phase-level TPS achievement is authoritative.
    const allPhasesTpsOk =
        CONFIG.phases.every((phase) => {

            const phaseTransactions =
                counterCount(
                    metric(
                        data,
                        phaseTag(
                            'transaction_count',
                            phase.name
                        )
                    )
                );

            const phaseDuration =
                parseDurationToSeconds(
                    phase.duration
                );

            const phaseActualTps =
                phaseDuration > 0
                    ? phaseTransactions /
                    phaseDuration
                    : 0;

            const achievement =
                pct(
                    phaseActualTps,
                    phase.targetTPS
                );

            return achievement >=
                CONFIG.reporting.minTpsAchievementPct;
        });

    const overallStatus =
        allPhasesTpsOk &&
            errOk
            ? 'PASS'
            : 'FAIL';

    // ===========================================================================
    // FINAL SUMMARY OBJECT
    // ===========================================================================

    const summary = {

        meta: {

            machineId:
                MACHINE_ID,

            testType:
                CONFIG.testType,

            startTime:
                startTime.toISOString(),

            endTime:
                endTime.toISOString(),

            durationSec,

            pageCount:
                CONFIG.urls.length,

            phaseCount:
                CONFIG.phases.length,

            // Used by merge-report.js to confirm every machine ran the
            // same phases/pages (in the same order) before merging.
            phaseNames:
                CONFIG.phases.map((p) => p.name),

            pageIds:
                CONFIG.urls.map((u) => u.id),

            leanMode:
                true,

            durationDetail:
                CONFIG.durationDetail,

            reportName:
                CONFIG.report.name,

            networkMetricsMode:
                CONFIG.networkMetrics,

            networkMetricKeys:
                NETWORK_TREND_METRICS.map((m) => m.key),

            acceptEncoding:
                CONFIG.acceptEncoding,

            vuPlan:
                VU_PLAN,

            cacheSampleRate:
                CACHE_SAMPLE_RATE,

            cacheSampleRatePct:
                CACHE_SAMPLE_RATE * 100,

            probeTps:
                CONFIG.cache.probeTps,

            expectedLatencySec:
                CONFIG.expectedLatencySec,

            gracefulStop:
                CONFIG.gracefulStop,

            errorRateFailThresholdPct:
                CONFIG.reporting.maxErrorRatePct,

            tpsAchievementFailThresholdPct:
                CONFIG.reporting.minTpsAchievementPct,
        },

        // -------------------------------------------------------------------------
        // OVERALL
        // -------------------------------------------------------------------------

        overall: {

            count:
                overallReqs,

            transactions:
                overallTransactions,

            passed:
                overallPassed,

            failed:
                overallFailed,

            errorPct:
                overallErrorPct,

            targetTps:
                overallTargetTps,

            actualTps:
                overallActualTps,

            dropped:
                overallDropped,

            avg:
                trendStat(
                    overallDurationM,
                    'avg'
                ),

            min:
                trendStat(
                    overallDurationM,
                    'min'
                ),

            p90:
                trendStat(
                    overallDurationM,
                    'p(90)'
                ),

            p95:
                trendStat(
                    overallDurationM,
                    'p(95)'
                ),

            p99:
                trendStat(
                    overallDurationM,
                    'p(99)'
                ),

            max:
                trendStat(
                    overallDurationM,
                    'max'
                ),

            // vus_max is a Gauge, so use max rather than Counter.count.
            vusMax:
                gaugeMax(
                    metric(
                        data,
                        'vus_max'
                    )
                ),

            classCounts:
                overallClassCounts,

            status:
                overallStatus,

            tpsOk:
                allPhasesTpsOk,

            errOk,

            // Informational only -- not part of `status`.
            dropOk,
        },

        // -------------------------------------------------------------------------
        // PHASES
        //
        // Each phase contains pages[].
        // -------------------------------------------------------------------------

        phases:
            CONFIG.phases.map(
                (phase) =>
                    buildPhaseRow(
                        data,
                        phase
                    )
            ),

        // -------------------------------------------------------------------------
        // CACHE
        // -------------------------------------------------------------------------

        cache:
            CONFIG.urls.map(
                (url) =>
                    buildCacheRow(
                        data,
                        url
                    )
            ),

        // -------------------------------------------------------------------------
        // Native aggregate metrics.
        //
        // Retained for future dashboarding.
        // -------------------------------------------------------------------------

        nativeMetrics:
            data.metrics,
    };

    return {

        [REPORT_HTML]:
            buildHtmlReport(
                summary
            ),

        [REPORT_JSON]:
            JSON.stringify(
                summary,
                null,
                2
            ),

        stdout:
            textSummary(
                data,
                {
                    indent: ' ',
                    enableColors: true,
                }
            ) +
            `\nTest complete. Overall status: ${summary.overall.status}. ` +
            `Transactions: ${summary.overall.transactions}, Requests: ${summary.overall.count}, ` +
            `Dropped (info only): ${summary.overall.dropped}. ` +
            `See ${REPORT_HTML} and ${REPORT_JSON}.\n`,
    };
}

#!/usr/bin/env node
/**
 * =============================================================================
 * merge-report.js
 * =============================================================================
 *
 * Combines multiple summary .json files (produced by k6-load-test-lean.js
 * when the SAME script runs on multiple machines in parallel) into ONE
 * report, so people look at a single combined report instead of N separate
 * ones.
 *
 * USAGE
 * -----
 *   node merge-report.js file1.json file2.json file3.json
 *   node merge-report.js --dir ./results
 *   node merge-report.js --dir ./results --name demo-run
 *   node merge-report.js --dir ./results --out ./combined/combined-report
 *
 * Options:
 *   --dir  <folder>  scan a folder (non-recursive) for *.json summaries.
 *                    Previously merged reports are skipped automatically.
 *   --name <name>    only merge summaries whose REPORT_NAME matches (handy
 *                    when several runs share one folder). Also the default
 *                    output prefix: <name>-combined.
 *   --out  <prefix>  output path prefix. Writes <prefix>.html and .json
 *                    (default: combined-report)
 *
 * Machines are told apart by the machine id inside each summary
 * (K6_MACHINE_ID on the generator), which is also part of each generator's
 * file name:  <REPORT_NAME>-<machineId>.json
 *
 * REPORT STRUCTURE (matches the single-machine report's order)
 * --------------------------------------------------------------
 * 1. Overall Summary        (+ a collapsible "source runs" note -- info only)
 * 2. Phase-wise Breakdown   (merged table, incl. Transactions -- same shape)
 * 3. Visual Overview        (charts -- summarizes section 2, nothing new)
 * 4. Overall HTTP Status Distribution
 * 5. Cache / Backend Breakdown
 * 6. Native k6 Metrics      (pointer to per-machine files -- not merged)
 *
 * WHAT'S EXACT VS APPROXIMATE
 * ----------------------------
 * Counts (transactions, requests, pass/fail, class counts, directive counts,
 * dropped) are SUMMED -- exact.
 *
 * avg / min / max latency are EXACT: avg is a count-weighted mean (which
 * reconstructs the true combined average), min/max are min-of-mins and
 * max-of-maxes.
 *
 * P90 / P95 / P99 are NOT mathematically exact when reconstructed from
 * per-machine percentiles alone (you can't average percentiles and get a
 * true percentile back). Two numbers are shown for each:
 *   - a count-weighted average across machines (usually close enough)
 *   - the max value observed on any single machine (a conservative,
 *     worst-node view)
 * True global percentiles would need raw per-request data or a histogram
 * backend (e.g. k6's Prometheus remote-write output) -- out of scope here.
 *
 * LEAN-MODE NOTES (k6-load-test-lean.js)
 * ---------------------------------------
 * - Cache Hit / Miss / Unknown and the Backend / Cache-Response indicator
 *   counts are recorded on a SAMPLE of responses. They are summed across
 *   machines (still a valid sample); use the Hit % column for the ratio.
 * - Age / Cache-Control / ETag / Vary come from a low-rate header probe, so
 *   their percentages use the number of probe responses as the basis.
 * - Latency detail depends on each generator's DURATION_DETAIL flag
 *   (phase_url | phase | summary). Cells a machine did not record are shown
 *   as n/a (never 0 ms) and are merged only over the machines that have them.
 *   Overall latency always comes from k6's native http_req_duration.
 * - Network metrics depend on each generator's NETWORK_METRICS flag. The
 *   merged table shows every metric that at least one machine reported and
 *   says how many machines contributed to it.
 *
 * ASSUMPTION ABOUT TARGET TPS
 * -----------------------------
 * Each machine is assumed to be running the SAME script, each driving its
 * own share of ONE larger aggregate rate (the standard distributed-k6
 * pattern). So the merged "Target TPS" for a phase is the SUM of every
 * machine's configured target for that phase, not any single machine's
 * value. If that's not how you're distributing load, treat the merged
 * Target TPS column with that in mind.
 *
 * NO EXTERNAL DEPENDENCIES. Plain Node.js (fs, path only). Charts render
 * client-side via Chart.js loaded from a CDN in the generated HTML.
 * =============================================================================
 */

function parseArgs(argv) {

    const args = { files: [], dir: null, out: null, name: null };

    for (let i = 0; i < argv.length; i++) {

        const arg = argv[i];

        if (arg === '--dir') {
            args.dir = argv[++i];
        } else if (arg === '--out') {
            args.out = argv[++i];
        } else if (arg === '--name') {
            args.name = argv[++i];
        } else if (arg === '--help' || arg === '-h') {
            args.help = true;
        } else if (!arg.startsWith('--')) {
            args.files.push(arg);
        }
    }

    return args;
}

function discoverFiles(args) {

    let files = [...args.files];

    if (args.dir) {

        if (!fs.existsSync(args.dir)) {
            throw new Error(`--dir "${args.dir}" does not exist.`);
        }

        const dirFiles = fs.readdirSync(args.dir)
            .filter((f) => f.toLowerCase().endsWith('.json'))
            .map((f) => path.join(args.dir, f));

        files = files.concat(dirFiles);
    }

    // De-dupe by resolved absolute path.
    const seen = new Set();
    const deduped = [];

    files.forEach((f) => {
        const resolved = path.resolve(f);
        if (!seen.has(resolved)) {
            seen.add(resolved);
            deduped.push(f);
        }
    });

    return deduped;
}

function loadSummaries(files, nameFilter) {

    const summaries = [];
    const seenMachines = new Set();

    files.forEach((filePath) => {

        let raw;

        try {
            raw = fs.readFileSync(filePath, 'utf8');
        } catch (err) {
            console.warn(`Skipping "${filePath}": cannot read file (${err.message})`);
            return;
        }

        let data;

        try {
            data = JSON.parse(raw);
        } catch (err) {
            console.warn(`Skipping "${filePath}": not valid JSON (${err.message})`);
            return;
        }

        if (!data.overall || !data.phases || !data.cache) {
            console.warn(`Skipping "${filePath}": doesn't look like a k6 summary (missing overall/phases/cache).`);
            return;
        }

        // A previously merged report has a "sources" list -- never re-merge it.
        if (data.sources) {
            console.log(`Skipping "${filePath}": this is a previously merged report.`);
            return;
        }

        if (nameFilter && !(data.meta && data.meta.reportName === nameFilter)) {
            console.log(`Skipping "${filePath}": REPORT_NAME is not "${nameFilter}".`);
            return;
        }

        const machineId =
            (data.meta && data.meta.machineId) ||
            path.basename(filePath, path.extname(filePath));

        if (seenMachines.has(machineId)) {
            console.warn(
                `Warning: machine id "${machineId}" appears in more than one file ` +
                `("${filePath}"). If these are different generators, give each a ` +
                `unique K6_MACHINE_ID; otherwise remove the duplicate run.`
            );
        }

        seenMachines.add(machineId);

        summaries.push({ filePath, machineId, data });
    });

    if (summaries.length === 0) {
        throw new Error('No valid k6 summary files found. Nothing to merge.');
    }

    return summaries;
}

// Confirms every summary shares the same phase names (in order) and the
// same page ids within each phase, since the merge logic assumes it's
// combining N runs of the SAME test config across machines.
function validateConsistentShape(summaries) {

    const reference = summaries[0];
    const refPhaseNames = reference.data.phases.map((p) => p.phase);

    const problems = [];

    summaries.slice(1).forEach((s) => {

        const phaseNames = s.data.phases.map((p) => p.phase);

        if (JSON.stringify(phaseNames) !== JSON.stringify(refPhaseNames)) {
            problems.push(
                `"${s.filePath}" has phases [${phaseNames.join(', ')}], ` +
                `but "${reference.filePath}" has [${refPhaseNames.join(', ')}].`
            );
            return;
        }

        s.data.phases.forEach((phase, i) => {

            const refPageIds = reference.data.phases[i].pages.map((p) => p.id).sort();
            const pageIds = phase.pages.map((p) => p.id).sort();

            if (JSON.stringify(pageIds) !== JSON.stringify(refPageIds)) {
                problems.push(
                    `"${s.filePath}" phase "${phase.phase}" has pages [${pageIds.join(', ')}], ` +
                    `expected [${refPageIds.join(', ')}].`
                );
            }
        });
    });

    if (problems.length > 0) {
        throw new Error(
            'Cannot merge -- these summaries are not from the same test config:\n  ' +
            problems.join('\n  ')
        );
    }

    // Thresholds should match too; warn (don't fail) if they don't, and
    // just use the first summary's thresholds for merged pass/fail.
    const refMeta = reference.data.meta || {};

    summaries.slice(1).forEach((s) => {

        const meta = s.data.meta || {};

        if (
            meta.errorRateFailThresholdPct !== refMeta.errorRateFailThresholdPct ||
            meta.tpsAchievementFailThresholdPct !== refMeta.tpsAchievementFailThresholdPct
        ) {
            console.warn(
                `Warning: "${s.filePath}" has different pass/fail thresholds than ` +
                `"${reference.filePath}". Using the first file's thresholds for the ` +
                `merged report.`
            );
        }
    });
}

// 4. GENERIC MERGE HELPERS

function sum(arr) {
    return arr.reduce((a, b) => a + (b || 0), 0);
}

function pct(part, whole) {
    return whole > 0 ? (part / whole) * 100 : 0;
}

function fmt(n, decimals = 2) {
    if (n === null || n === undefined || isNaN(n)) return 'n/a';
    return Number(n).toFixed(decimals);
}

function fmtBytes(n) {
    if (n === null || n === undefined || isNaN(n)) return 'n/a';
    const num = Number(n);
    if (num < 1024) return `${num.toFixed(0)} B`;
    if (num < 1024 * 1024) return `${(num / 1024).toFixed(2)} KB`;
    return `${(num / (1024 * 1024)).toFixed(2)} MB`;
}

function esc(str) {
    return String(str)
        .replace(/&/g, '&amp;')
        .replace(/</g, '&lt;')
        .replace(/>/g, '&gt;')
        .replace(/"/g, '&quot;')
        .replace(/'/g, '&#039;');
}

function unique(arr) {
    return [...new Set(arr.filter((v) => v !== undefined && v !== null))];
}

// Same duration-string parser as k6-load-test-lean.js ("5s", "10m", "1h" etc.)
function parseDurationToSeconds(dur) {
    const re = /(\d+)\s*(h|m|s)/g;
    let match, totalSeconds = 0, found = false;

    while ((match = re.exec(dur)) !== null) {
        found = true;
        const value = parseInt(match[1], 10);
        const unit = match[2];

        if (unit === 'h') totalSeconds += value * 3600;
        else if (unit === 'm') totalSeconds += value * 60;
        else totalSeconds += value;
    }

    if (!found) throw new Error(`Cannot parse duration: ${dur}`);
    return totalSeconds;
}

// Merges an array of { avg, min, max, p90, p95, p99, weight } entries into
// one combined trend. avg/min/max are exact; p90/p95/p99 get BOTH a
// weighted-average approximation and a max-across-entries figure -- see the
// file header for why percentiles can't be reconstructed exactly.
function mergeTrend(entries) {

    const num = (v) => typeof v === 'number' && !isNaN(v);

    // Entries with no recorded latency (e.g. DURATION_DETAIL=summary) are
    // ignored instead of being counted as 0 ms.
    const valid = entries.filter((e) => e.weight > 0 && num(e.avg));

    if (valid.length === 0) {
        return {
            avg: null, min: null, max: null,
            p90: null, p95: null, p99: null,
            p90Max: null, p95Max: null, p99Max: null,
        };
    }

    const withKey = (key) => valid.filter((e) => num(e[key]));

    const wavg = (key) => {
        const v = withKey(key);
        const w = sum(v.map((e) => e.weight));
        return w > 0 ? sum(v.map((e) => e[key] * e.weight)) / w : null;
    };

    const maxOf = (key) => {
        const v = withKey(key);
        return v.length > 0 ? Math.max(...v.map((e) => e[key])) : null;
    };

    const minOf = (key) => {
        const v = withKey(key);
        return v.length > 0 ? Math.min(...v.map((e) => e[key])) : null;
    };

    return {
        avg: wavg('avg'),
        min: minOf('min'),
        max: maxOf('max'),
        p90: wavg('p90'),
        p95: wavg('p95'),
        p99: wavg('p99'),
        p90Max: maxOf('p90'),
        p95Max: maxOf('p95'),
        p99Max: maxOf('p99'),
    };
}

// =============================================================================
// 5. MERGE: PAGES / PHASES / NETWORK METRICS / CACHE / OVERALL
// =============================================================================

function mergePage(pageEntries, errThresholdPct) {

    const first = pageEntries[0];

    const transactions = sum(pageEntries.map((p) => p.transactions));
    const count = sum(pageEntries.map((p) => p.count));
    const passed = sum(pageEntries.map((p) => p.passed));
    const failed = sum(pageEntries.map((p) => p.failed));

    const classCounts = {};
    STATUS_CLASSES.forEach((cls) => {
        classCounts[cls] = sum(pageEntries.map((p) => (p.classCounts && p.classCounts[cls]) || 0));
    });

    const errorPct = pct(failed, count);

    const trend = mergeTrend(
        pageEntries.map((p) => ({
            avg: p.avg, min: p.min, max: p.max, p90: p.p90, p95: p.p95, p99: p.p99,
            weight: p.count,
        }))
    );

    return {
        id: first.id,
        name: first.name,
        url: first.url,
        authEnabled: !!first.authEnabled,
        transactions,
        count,
        passed,
        failed,
        errorPct,
        classCounts,
        avg: trend.avg,
        min: trend.min,
        max: trend.max,
        p90: trend.p90,
        p95: trend.p95,
        p99: trend.p99,
        p90Max: trend.p90Max,
        p95Max: trend.p95Max,
        p99Max: trend.p99Max,
        status: errorPct <= errThresholdPct ? 'PASS' : 'FAIL',
    };
}

// Network metrics depend on each generator's NETWORK_METRICS flag (all / core
// / off), so the metric list is the UNION of what the machines reported, and
// each metric is merged only over the machines that reported it.
function mergeNetworkMetrics(networkMetricsPerMachine, reqWeights, transactionWeights) {

    const perMachine = networkMetricsPerMachine.map((nm) => nm || {});

    const known = NETWORK_TREND_METRICS.filter((m) =>
        perMachine.some((nm) => (nm.trends || []).some((t) => t.key === m.key))
    );

    const extras = [];

    perMachine.forEach((nm) => (nm.trends || []).forEach((t) => {
        const isKnown = NETWORK_TREND_METRICS.some((m) => m.key === t.key);
        if (!isKnown && !extras.some((e) => e.key === t.key)) {
            extras.push({ key: t.key, label: t.label || t.key });
        }
    }));

    const trends = known.concat(extras).map((m) => {

        const entries = [];

        perMachine.forEach((nm, i) => {

            const t = (nm.trends || []).find((tr) => tr.key === m.key);

            if (!t) return;

            entries.push({
                avg: t.avg, min: t.min, max: t.max, p90: t.p90, p95: t.p95, p99: t.p99,
                weight: reqWeights[i],
            });
        });

        return {
            key: m.key,
            label: m.label,
            ...mergeTrend(entries),
            machinesReporting: entries.length,
        };
    });

    const dataSentBytes = sum(perMachine.map((nm) => nm.dataSentBytes));
    const dataReceivedBytes = sum(perMachine.map((nm) => nm.dataReceivedBytes));

    const iterEntries = [];

    perMachine.forEach((nm, i) => {

        const it = nm.iterationDuration;

        if (!it) return;

        iterEntries.push({
            avg: it.avg, min: it.min, max: it.max,
            p90: it.p90, p95: it.p95, p99: it.p99,
            weight: transactionWeights[i],
        });
    });

    const iterationDuration =
        iterEntries.length > 0
            ? { ...mergeTrend(iterEntries), machinesReporting: iterEntries.length }
            : null;

    return { trends, dataSentBytes, dataReceivedBytes, iterationDuration };
}

function mergePhase(phaseEntries, thresholds) {

    // phaseEntries: [{ machineId, phase }] -- one entry per machine, same
    // phase name, already validated to share the same page ids.

    const first = phaseEntries[0].phase;

    const transactions = sum(phaseEntries.map((e) => e.phase.transactions));
    const count = sum(phaseEntries.map((e) => e.phase.count));
    const passed = sum(phaseEntries.map((e) => e.phase.passed));
    const failed = sum(phaseEntries.map((e) => e.phase.failed));
    const dropped = sum(phaseEntries.map((e) => e.phase.dropped));

    const classCounts = {};
    STATUS_CLASSES.forEach((cls) => {
        classCounts[cls] = sum(phaseEntries.map((e) => (e.phase.classCounts && e.phase.classCounts[cls]) || 0));
    });

    const errorPct = pct(failed, count);

    // Each machine is assumed to drive its own share of one larger
    // aggregate target rate -- see file header note.
    const targetTps = sum(phaseEntries.map((e) => e.phase.targetTps));

    const durationSeconds = parseDurationToSeconds(first.duration);
    const actualTps = durationSeconds > 0 ? transactions / durationSeconds : 0;
    const tpsAchievementPct = pct(actualTps, targetTps);

    const trend = mergeTrend(
        phaseEntries.map((e) => ({
            avg: e.phase.avg, min: e.phase.min, max: e.phase.max,
            p90: e.phase.p90, p95: e.phase.p95, p99: e.phase.p99,
            weight: e.phase.count,
        }))
    );

    const tpsOk = tpsAchievementPct >= thresholds.tpsAchievementFailThresholdPct;
    const errOk = errorPct <= thresholds.errorRateFailThresholdPct;
    const dropOk = dropped === 0; // informational only, not part of status

    // Merge pages: for each page id (same across all machines, validated
    // upfront), collect that page's entry from every machine and merge.
    const pageIds = first.pages.map((p) => p.id);

    const pages = pageIds.map((id) => {
        const entriesForPage = phaseEntries.map((e) => e.phase.pages.find((p) => p.id === id));
        return mergePage(entriesForPage, thresholds.errorRateFailThresholdPct);
    });

    const networkMetrics = mergeNetworkMetrics(
        phaseEntries.map((e) => e.phase.networkMetrics),
        phaseEntries.map((e) => e.phase.count),
        phaseEntries.map((e) => e.phase.transactions)
    );

    // httpReqFailedPct is approximated as the merged error rate for this
    // phase (k6's http_req_failed rate and our failed-class definition
    // both key off the same 200-399 = success rule).
    networkMetrics.httpReqFailedPct = errorPct;

    return {
        phase: first.phase,
        targetTps,
        transactions,
        actualTps,
        tpsAchievementPct,
        duration: first.duration,
        avg: trend.avg,
        min: trend.min,
        max: trend.max,
        p90: trend.p90,
        p95: trend.p95,
        p99: trend.p99,
        p90Max: trend.p90Max,
        p95Max: trend.p95Max,
        p99Max: trend.p99Max,
        count,
        passed,
        failed,
        errorPct,
        classCounts,
        dropped,
        tpsOk,
        errOk,
        dropOk,
        status: tpsOk && errOk ? 'PASS' : 'FAIL',
        pages,
        networkMetrics,
        machineCount: phaseEntries.length,
    };
}

// Static-header percentages (Age / Cache-Control / ETag / Vary) are based on
// the number of header-probe responses when the summary has it (lean
// script); older summaries fall back to transactions.
function presenceBasis(entry) {
    return entry.probeSamples !== undefined ? entry.probeSamples : entry.transactions;
}

function mergeCachePage(entries) {

    const first = entries[0];

    if (first.strategy === 'not-applicable' || first.strategy === 'not-observable') {
        return {
            id: first.id, name: first.name, url: first.url,
            strategy: first.strategy, note: first.note,
        };
    }

    const hit = sum(entries.map((e) => e.hit));
    const miss = sum(entries.map((e) => e.miss));
    const unknown = sum(entries.map((e) => e.unknown));
    const backend = sum(entries.map((e) => e.backend));
    const cacheResp = sum(entries.map((e) => e.cacheResp));
    const transactions = sum(entries.map((e) => e.transactions));
    const probeSamples = sum(entries.map(presenceBasis));
    const etagPresent = sum(entries.map((e) => e.etagPresent));
    const varyPresent = sum(entries.map((e) => e.varyPresent));

    const hitPct = pct(hit, hit + miss);
    const etagPct = pct(etagPresent, probeSamples);
    const varyPct = pct(varyPresent, probeSamples);

    // ---- Age ----

    const ageCountOf = (e) => {
        if (!e.age) return 0;
        if (e.age.sampleCount !== undefined) return e.age.sampleCount;
        return Math.round(((e.age.presentPct || 0) / 100) * presenceBasis(e));
    };

    const ageSampleCount = sum(entries.map(ageCountOf));

    const ageTrend = mergeTrend(
        entries
            .filter((e) => ageCountOf(e) > 0)
            .map((e) => ({
                avg: e.age.avg, min: e.age.min, max: e.age.max, p90: e.age.p90,
                weight: ageCountOf(e),
            }))
    );

    const age = {
        present: ageSampleCount > 0,
        presentPct: pct(ageSampleCount, probeSamples),
        sampleCount: ageSampleCount,
        avg: ageTrend.avg,
        min: ageTrend.min,
        max: ageTrend.max,
        p90: ageTrend.p90,
    };

    // ---- Cache-Control ----

    const ccSampleCount = sum(entries.map((e) => (e.cacheControl && e.cacheControl.sampleCount) || 0));

    const directiveCounts = {};
    CACHE_CONTROL_DIRECTIVES.forEach((dir) => {
        directiveCounts[dir] = sum(
            entries.map((e) => (e.cacheControl && e.cacheControl.directiveCounts && e.cacheControl.directiveCounts[dir]) || 0)
        );
    });

    const directiveSummary =
        CACHE_CONTROL_DIRECTIVES
            .map((dir) => (directiveCounts[dir] > 0 ? `${dir}:${directiveCounts[dir]}` : null))
            .filter(Boolean)
            .join(', ') || 'n/a';

    const maxAgeWeightTotal = directiveCounts['max-age'];

    const avgMaxAge =
        maxAgeWeightTotal > 0
            ? sum(entries.map((e) => {
                const w = (e.cacheControl && e.cacheControl.directiveCounts && e.cacheControl.directiveCounts['max-age']) || 0;
                const v = (e.cacheControl && e.cacheControl.avgMaxAge) || 0;
                return v * w;
            })) / maxAgeWeightTotal
            : 0;

    let consistent = true;
    const parts = [];

    CACHE_CONTROL_DIRECTIVES.forEach((dir) => {

        const c = directiveCounts[dir];
        if (c === 0) return;

        if (c < ccSampleCount) consistent = false;

        parts.push(dir === 'max-age' ? `max-age=${Math.round(avgMaxAge)}` : dir);
    });

    const typicalValue =
        ccSampleCount > 0
            ? (parts.length > 0 ? parts.join(', ') : 'present (no tracked directives matched)')
            : 'n/a';

    const cacheControl = {
        present: ccSampleCount > 0,
        presentPct: pct(ccSampleCount, probeSamples),
        typicalValue,
        consistent,
        avgMaxAge,
        directiveCounts,
        directiveSummary,
        sampleCount: ccSampleCount,
    };

    return {
        id: first.id, name: first.name, url: first.url, strategy: first.strategy,
        hit, miss, unknown, hitPct, backend, cacheResp, transactions, probeSamples,
        sampled: hit + miss + unknown,
        age, cacheControl, etagPresent, etagPct, varyPresent, varyPct,
    };
}

function mergeOverall(mergedPhases, summaries, thresholds) {

    const count = sum(mergedPhases.map((p) => p.count));
    const transactions = sum(mergedPhases.map((p) => p.transactions));
    const passed = sum(mergedPhases.map((p) => p.passed));
    const failed = sum(mergedPhases.map((p) => p.failed));
    const dropped = sum(mergedPhases.map((p) => p.dropped));

    const classCounts = {};
    STATUS_CLASSES.forEach((cls) => {
        classCounts[cls] = sum(mergedPhases.map((p) => p.classCounts[cls] || 0));
    });

    const errorPct = pct(failed, count);

    const targetTps = Math.max(...mergedPhases.map((p) => p.targetTps));
    const totalDurationSec = sum(mergedPhases.map((p) => parseDurationToSeconds(p.duration)));
    const actualTps = totalDurationSec > 0 ? transactions / totalDurationSec : 0;

    // Overall latency comes from each machine's own native http_req_duration
    // (always recorded, whatever DURATION_DETAIL was). Phase-derived values are
    // only a fallback for older summaries.
    let trend = mergeTrend(
        summaries.map((s) => {
            const o = s.data.overall || {};
            return {
                avg: o.avg, min: o.min, max: o.max,
                p90: o.p90, p95: o.p95, p99: o.p99,
                weight: o.count,
            };
        })
    );

    if (trend.avg === null) {
        trend = mergeTrend(
            mergedPhases.map((p) => ({
                avg: p.avg, min: p.min, max: p.max, p90: p.p90, p95: p.p95, p99: p.p99,
                weight: p.count,
            }))
        );
    }

    const vusMax = sum(summaries.map((s) => (s.data.overall && s.data.overall.vusMax) || 0));

    const tpsOk = mergedPhases.every((p) => p.tpsOk);
    const errOk = errorPct <= thresholds.errorRateFailThresholdPct;
    const dropOk = dropped === 0;

    return {
        count, transactions, passed, failed, errorPct, targetTps, actualTps, dropped,
        avg: trend.avg, min: trend.min, max: trend.max,
        p90: trend.p90, p95: trend.p95, p99: trend.p99,
        p90Max: trend.p90Max, p95Max: trend.p95Max, p99Max: trend.p99Max,
        vusMax, classCounts,
        status: tpsOk && errOk ? 'PASS' : 'FAIL',
        tpsOk, errOk, dropOk,
    };
}

// 6. TOP-LEVEL MERGE
// =============================================================================

function mergeSummaries(summaries) {

    validateConsistentShape(summaries);

    const reference = summaries[0].data;
    const thresholds = {
        errorRateFailThresholdPct: (reference.meta && reference.meta.errorRateFailThresholdPct) ?? 10,
        tpsAchievementFailThresholdPct: (reference.meta && reference.meta.tpsAchievementFailThresholdPct) ?? 90,
    };

    const phaseNames = reference.phases.map((p) => p.phase);

    const mergedPhases = phaseNames.map((name) => {

        const phaseEntries = summaries.map((s) => ({
            machineId: s.machineId,
            phase: s.data.phases.find((p) => p.phase === name),
        }));

        return mergePhase(phaseEntries, thresholds);
    });

    const pageIds = reference.cache.map((c) => c.id);

    const mergedCache = pageIds.map((id) => {
        const entries = summaries.map((s) => s.data.cache.find((c) => c.id === id));
        return mergeCachePage(entries);
    });

    const overall = mergeOverall(mergedPhases, summaries, thresholds);

    const startTimes = summaries.map((s) => new Date(s.data.meta.startTime).getTime());
    const endTimes = summaries.map((s) => new Date(s.data.meta.endTime).getTime());

    const metas = summaries.map((s) => s.data.meta || {});

    const meta = {
        reportName: reference.meta.reportName || 'k6-report',
        testType: reference.meta.testType,
        startTime: new Date(Math.min(...startTimes)).toISOString(),
        endTime: new Date(Math.max(...endTimes)).toISOString(),
        durationSec: (Math.max(...endTimes) - Math.min(...startTimes)) / 1000,
        pageCount: reference.meta.pageCount,
        phaseCount: reference.meta.phaseCount,
        machineCount: summaries.length,
        machineIds: summaries.map((s) => s.machineId),
        leanMode: metas.some((m) => m.leanMode),
        networkMetricsModes: unique(metas.map((m) => m.networkMetricsMode)),
        durationDetails: unique(metas.map((m) => m.durationDetail)),
        acceptEncodings: unique(metas.map((m) => m.acceptEncoding)),
        errorRateFailThresholdPct: thresholds.errorRateFailThresholdPct,
        tpsAchievementFailThresholdPct: thresholds.tpsAchievementFailThresholdPct,
    };

    // Kept for the "source runs" info note -- deliberately lightweight,
    // not a full dashboard section (per requirements: nice-to-have, not
    // the primary focus of the combined report).
    const sources = summaries.map((s) => ({
        machineId: s.machineId,
        filePath: s.filePath,
        transactions: s.data.overall.transactions,
        errorPct: s.data.overall.errorPct,
        status: s.data.overall.status,
        networkMetricsMode: (s.data.meta && s.data.meta.networkMetricsMode) || 'n/a',
        cacheSampleRatePct: s.data.meta ? s.data.meta.cacheSampleRatePct : undefined,
        acceptEncoding: (s.data.meta && s.data.meta.acceptEncoding) || 'n/a',
    }));

    return { meta, overall, phases: mergedPhases, cache: mergedCache, sources };
}

function main() {

    const args = parseArgs(process.argv.slice(2));

    if (args.help || (args.files.length === 0 && !args.dir)) {
        printHelp();
        process.exit(args.help ? 0 : 1);
    }

    const files = discoverFiles(args);

    console.log(`Merging up to ${files.length} summary file(s):`);
    files.forEach((f) => console.log(`  - ${f}`));

    const summaries = loadSummaries(files, args.name);
    const combined = mergeSummaries(summaries);

    const outPrefix =
        args.out || (args.name ? `${args.name}-combined` : 'combined-report');

    const outDir = path.dirname(outPrefix) || '.';
    if (!fs.existsSync(outDir)) {
        fs.mkdirSync(outDir, { recursive: true });
    }

    const htmlPath = `${outPrefix}.html`;
    const jsonPath = `${outPrefix}.json`;

    fs.writeFileSync(htmlPath, buildHtmlReport(combined));
    fs.writeFileSync(jsonPath, JSON.stringify(combined, null, 2));

    console.log(`\nMerged ${summaries.length} machine(s): ${combined.meta.machineIds.join(', ')}`);
    console.log(`Combined report written:`);
    console.log(`  ${htmlPath}`);
    console.log(`  ${jsonPath}`);
    console.log(`\nOverall merged status: ${combined.overall.status}`);
}

#!/usr/bin/env bash
# =============================================================================
# gcp-run.sh  --  run the k6 script on several GCP VMs from Cloud Shell
# =============================================================================
#
# Run this in Cloud Shell, in the folder that holds k6-load-test-lean.js and
# merge-report.js. No tmux/screen needed: the test runs on each VM in the
# background, so it keeps going if you close Cloud Shell.
#
#   ./gcp-run.sh setup     install k6 + OS tuning on every VM      (once)
#   ./gcp-run.sh agent     install the Ops Agent (memory graphs)   (once)
#   ./gcp-run.sh check     confirm every VM is ready
#   ./gcp-run.sh copy      upload the k6 script to every VM
#   ./gcp-run.sh start     start the test on ALL VMs at the same second
#   ./gcp-run.sh status    one line per VM: running?, CPU load, memory, tcp
#   ./gcp-run.sh logs N    last lines of the k6 log on VM number N
#   ./gcp-run.sh stop      stop the test gracefully (report is still written)
#   ./gcp-run.sh collect   download every VM's report + json to ./results
#   ./gcp-run.sh merge     build the ONE combined report from ./results
#
# Settings: edit the block below, or override on the command line, e.g.
#   RUN_PROFILE=load REPORT_NAME=load-1h ./gcp-run.sh start
#
# IMPORTANT: targetTPS inside the k6 script's profile is PER VM.
#   6 VMs x 5,000 TPS (profile "load") = 30,000 TPS in total.
#   Edit the profile array in the k6 script first if you want a different total.
# =============================================================================

set -u

# ------------------------------ EDIT THESE -----------------------------------
PROJECT="${PROJECT:-$(gcloud config get-value project 2>/dev/null)}"
ZONE="${ZONE:-us-central1-a}"          # zone the VMs are in
VM_PREFIX="${VM_PREFIX:-loadgen}"      # VMs are named loadgen-1 ... loadgen-6
VM_COUNT="${VM_COUNT:-6}"
VM_NAMES="${VM_NAMES:-}"               # or list them: "vm-a vm-b vm-c"
K6_SCRIPT="${K6_SCRIPT:-k6-load-test-lean.js}"
MERGE_SCRIPT="${MERGE_SCRIPT:-merge-report.js}"

REPORT_NAME="${REPORT_NAME:-my-test}"  # same on every VM (set automatically)

USE_IAP="${USE_IAP:-true}"             # true if the VMs have no external IP
EXTRA_K6_ARGS="${EXTRA_K6_ARGS:-}"     # e.g. "-e DURATION_DETAIL=summary"

# Runs "<function> <vm> [args]" on every VM in parallel; prefixes each output
# line with the VM name; returns non-zero if any VM failed.
run_on_all() {
    local fn=$1; shift
    local pids=() vm p fail=0
    for vm in "${VMS[@]}"; do
        ( set -o pipefail; "$fn" "$vm" "$@" 2>&1 | sed -u "s/^/[$vm] /" ) &
        pids+=($!)
    done
    for p in "${pids[@]}"; do wait "$p" || fail=1; done
    [ "$fail" -ne 0 ] && echo "!! at least one VM reported an error (see lines above)"
    return $fail
}

# ------------------------- files that run ON the VMs -------------------------

write_vm_files() {

cat > "$WORK/vm-setup.sh" <<'EOF'
#!/usr/bin/env bash
set -e
K6_VERSION="$1"
command -v curl >/dev/null || { sudo apt-get update -y && sudo apt-get install -y curl; }
if ! command -v k6 >/dev/null || ! k6 version | grep -q "${K6_VERSION#v}"; then
    ARCH=amd64; [ "$(uname -m)" = "aarch64" ] && ARCH=arm64
    cd /tmp
    curl -fsSL -o k6.tgz "https://github.com/grafana/k6/releases/download/${K6_VERSION}/k6-${K6_VERSION}-linux-${ARCH}.tar.gz"
    tar xzf k6.tgz
    sudo install -m 0755 "k6-${K6_VERSION}-linux-${ARCH}/k6" /usr/local/bin/k6
fi
# OS tuning for many connections
sudo tee /etc/sysctl.d/99-k6.conf >/dev/null <<SYS
net.ipv4.ip_local_port_range = 1024 65535
net.ipv4.tcp_tw_reuse = 1
net.core.somaxconn = 65535
fs.file-max = 2000000
SYS
sudo sysctl --system >/dev/null
sudo tee /etc/security/limits.d/99-k6.conf >/dev/null <<LIM
* soft nofile 1000000
* hard nofile 1000000
LIM
k6 version
EOF

cat > "$WORK/vm-start.sh" <<'EOF'
#!/usr/bin/env bash
# args: SCRIPT_NAME START_EPOCH PROFILE REPORT_NAME MACHINE_ID [extra k6 args]
SCRIPT="$1"; START="$2"; PROFILE="$3"; REPORT="$4"; MID="$5"; shift 5
mkdir -p "$HOME/results"
ulimit -n 1000000 2>/dev/null || ulimit -n 65535 2>/dev/null || true
d=$(( START - $(date +%s) ))
[ "$d" -gt 0 ] && sleep "$d"
echo "start $(date -Is) machine=$MID profile=$PROFILE report=$REPORT"
exec k6 run "$HOME/$SCRIPT" \
    -e RUN_PROFILE="$PROFILE" -e REPORT_NAME="$REPORT" \
    -e K6_MACHINE_ID="$MID" -e REPORT_DIR="$HOME/results" "$@"
EOF

cat > "$WORK/vm-status.sh" <<'EOF'
#!/usr/bin/env bash
if pgrep -x k6 >/dev/null; then state=RUNNING; else state=STOPPED; fi
read -r l1 _ < /proc/loadavg
mem=$(free -m | awk 'NR==2{printf "%d/%dMB(%d%%)", $3,$2,$3*100/$2}')
k6mem=$(ps -o rss= -C k6 | awk '{s+=$1} END{printf "%d", s/1024}')
tcp=$(awk '/^TCP:/{print $3}' /proc/net/sockstat)
printf "%s load1=%s cpus=%s mem=%s k6_rss=%sMB tcp=%s files=%s\n" \
    "$state" "$l1" "$(nproc)" "$mem" "${k6mem:-0}" "$tcp" "$(ls "$HOME/results" 2>/dev/null | wc -l)"
EOF
chmod +x "$WORK"/vm-*.sh
}

# k6 Load Testing Framework — Operator Guide

Covers: which command to run for each scenario, what's a flag vs. what you
edit in the script, and how to launch/monitor/collect results across
multiple GCP VMs from Cloud Shell without tmux.

Files: `k6-load-test-lean.js` (the test), `merge-report.js` (combines
multiple VMs' JSON output into one report).

---

## 1. One-time setup, per VM

```bash
# confirm k6 is installed (you said this is already done)
k6 version

# working directory
mkdir -p ~/k6/results
cd ~/k6
# copy k6-load-test-lean.js and merge-report.js here (scp, git clone, etc.)

# raise file-descriptor limit for THIS shell session -- do this every time
# before launching a run, in the same command chain (see section 6), since
# it's not persistent across logins unless you also edit limits.conf
ulimit -n 65535
```

Persistent version (survives reboots/new sessions) — run once per VM:

```bash
sudo tee -a /etc/security/limits.conf >/dev/null <<'EOF'
*    soft    nofile    65535
*    hard    nofile    65535
EOF
sudo sysctl -w net.ipv4.ip_local_port_range="1024 65535"
sudo sysctl -w net.core.somaxconn=65535
```

---

## 2. RUN_PROFILE — pick the scenario

One flag selects the whole load pattern. Nothing else is required to run it.

| RUN_PROFILE | What it does | Default duration | When to use |
|---|---|---|---|
| `smoke` (default if omitted) | Tiny 4-step ramp (4→50 tps), a few seconds | ~20s | Sanity-check the script/target work before anything else |
| `load` | One steady TPS level | 1h | Confirm normal expected traffic behaves; baseline for comparison |
| `stress` | Rising steps (5k→30k tps, 6×10m) | 1h | **Find the real breaking point of one VM.** Always run this first — its output (p95 latency, the step where errors/drops start) is what you use to fix the placeholder VU numbers in every other profile |
| `spike` | Baseline (2k tps) with sharp bursts (20k tps), repeated 3×, + recovery | ~2h9m | Check recovery behavior around sudden traffic surges |
| `endurance` | One steady level, per-VM target 10k tps | 6h | The actual long soak. Defaults to the cheapest memory/detail settings automatically (see §4) |

The *shape* of each pattern (TPS levels, number of steps/spikes, every
duration, and the VU pair) is a plain array literal in the script — **not**
a pile of CLI flags. Edit it directly. See §5.

---

## 3. Quick-start commands (single VM)

```bash
# 1) Smoke test -- confirm the script/target work
k6 run k6-load-test-lean.js

# 2) Stress test -- run this FIRST on one representative VM, always
k6 run k6-load-test-lean.js -e RUN_PROFILE=stress -e REPORT_NAME=stress-run

# 3) Load test
k6 run k6-load-test-lean.js -e RUN_PROFILE=load -e REPORT_NAME=load-run

# 4) Spike test
k6 run k6-load-test-lean.js -e RUN_PROFILE=spike -e REPORT_NAME=spike-run

# 5) Endurance test (6h, per-VM target as set in the script -- see §5)
k6 run k6-load-test-lean.js -e RUN_PROFILE=endurance -e REPORT_NAME=endurance-run
```

Each run writes `<REPORT_NAME>-<machine>.html` and `.json` to the current
directory (or `REPORT_DIR` if set). Open the `.html` file — that's the
report; no separate viewer needed.

## 4. Flag reference — what each option does, when to use it

All flags are optional; pass with `-e NAME=value`. Defaults shown in `[ ]`.

| Flag | Values / example | Default | What it does | When to touch it |
|---|---|---|---|---|
| `RUN_PROFILE` | `smoke\|load\|stress\|spike\|endurance` | `smoke` | Selects the load pattern (§2) | Every run |
| `TEST_TYPE` | any string | = `RUN_PROFILE` | Cosmetic label shown in the report header | Only if you want the report to say something other than the profile name |
| `REPORT_NAME` | e.g. `endurance-run` | `k6-report` | Base filename for the `.html`/`.json` output | Set consistently across VMs so `merge-report.js` can find them all |
| `REPORT_DIR` | e.g. `~/k6/results` | current dir | Folder the report files are written into | Multi-VM runs — keep it consistent per VM so collection is easy |
| `K6_MACHINE_ID` | e.g. `gen1` | hostname | Identifies this generator in filenames and in the merged report | **Required, unique per VM**, whenever running distributed |
| `REPORT_APPEND_MACHINE_ID` | `true`/`false` | `true` | Whether `-<machine>` is appended to filenames | Leave as-is unless you're intentionally running single-VM and want a clean filename |
| `NETWORK_METRICS` | `all\|core\|off` | profile's default | Controls how many extra per-phase timing series (`blocked`, `connecting`, `tls`, `sending`, `waiting`, `receiving`, `iteration_duration`) are tracked. Directly trades off memory vs. detail | `all` for load/spike/stress (detail is cheap at those durations); `off` is already the endurance default — leave it |
| `DURATION_DETAIL` | `phase_url\|phase\|summary` | profile's default | Controls how many duplicate copies of `http_req_duration` (the single biggest memory cost on a long soak) are kept | `phase_url` (full per-page latency) is fine for ≤2h runs; endurance already defaults to `summary` — only loosen this if you specifically need per-page latency on the 6h run and have confirmed the VM has RAM headroom |
| `PHASES_JSON` | JSON array | — | **Escape hatch.** Fully replaces the active profile's phases for a one-off custom shape, without editing the file | Rare; prefer editing the array in §5 instead — it's the same effort and stays in version control |
| `PRE_ALLOCATED_VUS` / `MAX_VUS` | integers | — | Global VU pin, used only as a fallback | **Has no effect on any of the 5 built-in profiles** — every phase already hardcodes its own VU pair (§5), which always wins. Only relevant if you clear those fields or use `PHASES_JSON` |
| `PHASE_VUS` | JSON, e.g. `{"load_steady":{"pre":600,"max":800}}` | — | Per-phase VU pin, used only as a fallback | Same caveat as above |
| `EXPECTED_LATENCY_SEC` | number, e.g. `0.08` | `0.1` | Latency assumed by the VU-sizing formula | Same caveat — dead code for the built-in profiles; only used if a phase has no explicit VU pair |
| `MAX_VU_MULTIPLIER` | number | `2` | `maxVUs = preAllocated × this`, formula fallback only | Same caveat |
| `GRACEFUL_STOP` | e.g. `10s` | `5s` | How long a finishing phase is given to drain in-flight requests before the next phase starts | Raise slightly if you see requests cut off mid-response between phases |
| `ACCEPT_ENCODING` | e.g. `gzip`, `none` | `gzip` | `Accept-Encoding` header sent | Set `none` if you specifically want to test uncompressed responses |
| `BASIC_AUTH_USER` / `BASIC_AUTH_PASS` | strings | — | Shared credentials for pages with `auth: true` | Only if your target requires basic auth (see §5 for opting a page in) |
| `CACHE_SAMPLE_RATE` | `0..1` | auto | Overrides the automatic sampling rate for cache-header observability | Rarely — the automatic rate already adapts to TPS |
| `CACHE_SAMPLES_PER_SEC` | integer | `1000` | Cap used to compute the automatic sample rate | Rarely |
| `PROBE_TPS` | integer, `0` disables | `2` | Rate of the low-volume scenario that captures static headers (ETag, Vary, Cache-Control, Age) | Set `0` if you don't care about cache-header detail at all |

## 5. What you edit directly in the script (no flag for these)

Open `k6-load-test-lean.js`:

**Target pages / URLs — `CONFIG.urls` array** (search for `urls:`)
```js
urls: [
    { id: 'homepage', name: 'Homepage', url: 'https://your-target/page1',
      method: 'GET', weight: 1, provider: 'gcp-cdn' },
    // add/remove pages, adjust `weight` to change traffic distribution,
    // add `auth: true` to use BASIC_AUTH_USER/PASS on that page,
    // or `headers: {...}` to override headers for just that page
],
```

**Load pattern shape + VU sizing — `RUN_PROFILES` object, section 0c** (search
for `const RUN_PROFILES`). Every phase in every profile hardcodes its own
`targetTPS`, `duration`, `preAllocatedVUs`, `maxVUs`:
```js
endurance: {
    durationDetail: 'summary',
    networkMetrics: 'off',
    phases: [
        { name: 'endurance_steady', targetTPS: 10000, duration: '6h',
          preAllocatedVUs: 1100, maxVUs: 1500 },
    ],
},
```
**These VU numbers are placeholders** (assume ~100ms p95). After the
stress-test calibration (§3, step 2), replace them everywhere:
`preAllocatedVUs = ceil(targetTPS × measured_p95_sec)`, `maxVUs ≈ 1.3×`
that. Identical VMs share one calibration — you don't need to repeat this
per VM.

To change how many steps a stress test has, how many bursts a spike has, or
any duration anywhere — add/remove/edit entries in that phase's array
directly.

**Total TPS across VMs = (VMs you actually run) × (targetTPS in that
phase).** If you use all 4 VMs at the current `endurance` setting of 10000
tps each, that's 40k total. Edit `targetTPS` in the `endurance` phase (and
its VU pair proportionally) if you want a different total — e.g. `5000` per
VM × 4 VMs = 20k, or run the same 10000-tps script on only 2 of the 4 VMs.

**Pass/fail thresholds — `CONFIG.reporting`** (search for `reporting:`)
```js
reporting: {
    maxErrorRatePct: 10.0,      // report FAILs above this error %
    minTpsAchievementPct: 90.0, // flags if actual TPS falls below this % of target
},
```

## 6. Running all 4 VMs at once from Cloud Shell — no tmux

**Why not just `ssh` and leave it running:** Cloud Shell itself disconnects
after ~20 minutes idle, and closing the browser tab kills the local shell.
Neither of those has to matter — the fix is to make the k6 process on each
*remote* VM independent of the SSH session that started it, using
`nohup` + backgrounding (`&`) + `disown`. That combination detaches the
process from its parent shell so it survives the SSH connection closing,
Cloud Shell timing out, or you closing the browser entirely — no tmux,
screen, or systemd unit required.

### 6.1 Launch on all 4 VMs simultaneously

```bash
ZONE=us-central1-a
VMS=(vm-gen1 vm-gen2 vm-gen3 vm-gen4)     # your actual instance names
PROFILE=endurance
RUN_NAME=endurance-run

for i in "${!VMS[@]}"; do
  MID="gen$((i+1))"
  gcloud compute ssh "${VMS[$i]}" --zone="$ZONE" --command="
    cd ~/k6 &&
    ulimit -n 65535 &&
    nohup k6 run k6-load-test-lean.js \
      -e RUN_PROFILE=$PROFILE \
      -e K6_MACHINE_ID=$MID \
      -e REPORT_NAME=$RUN_NAME \
      -e REPORT_DIR=~/k6/results \
      > ~/k6/results/${RUN_NAME}-${MID}.log 2>&1 < /dev/null &
    disown
    echo STARTED_${MID}
  " &
done
wait
echo "All 4 launch commands returned."
```

- The **outer** `&` on each `gcloud compute ssh ...` line backgrounds the
  local SSH call in Cloud Shell, so all 4 VMs get the command fired at
  essentially the same time instead of one after another.
- The **inner** `nohup ... &` + `disown` backgrounds and detaches the k6
  process on the remote VM itself. The SSH command returns almost
  immediately (it started a background job, not waited for 6 hours), which
  is why `wait` finishes quickly rather than blocking for 6 hours.
- Run this same block with `PROFILE=stress`, `PROFILE=load`, or
  `PROFILE=spike` for the other scenarios — same pattern.

### 6.2 Confirm they actually started

```bash
for m in vm-gen1 vm-gen2 vm-gen3 vm-gen4; do
  echo "== $m =="
  gcloud compute ssh "$m" --zone="$ZONE" --command="pgrep -af k6 || echo NOT RUNNING"
done
```

## 7. Monitoring live, without losing the run if you disconnect

Each of the commands below opens its **own** short-lived SSH connection
just to read/stream a log file. If Cloud Shell disconnects mid-`tail`, the
k6 process on the VM is completely unaffected (see §6) — you just
reconnect and run the command again.

**Watch one VM's log live:**
```bash
gcloud compute ssh vm-gen1 --zone="$ZONE" --command="tail -n 50 -f ~/k6/results/endurance-run-gen1.log"
```
Ctrl+C stops watching; the remote test keeps running.

**Watch all 4 VMs at once, interleaved, in one Cloud Shell window** (this
is the "no tmux" equivalent of a multi-pane view):
```bash
for m in vm-gen1 vm-gen2 vm-gen3 vm-gen4; do
  gcloud compute ssh "$m" --zone="$ZONE" \
    --command="tail -n 0 -f ~/k6/results/endurance-run-${m#vm-}.log | sed \"s/^/[$m] /\"" &
done
wait
```
(adjust the log filename to match your `K6_MACHINE_ID` mapping). Ctrl+C
kills the local watchers only — same guarantee as above.

**Check a VM is healthy (CPU/mem), while the test is running:**
```bash
gcloud compute ssh vm-gen1 --zone="$ZONE" --command="top -bn1 | head -15; free -h"
```

**Check whether a run has finished** (process gone + report file exists):
```bash
gcloud compute ssh vm-gen1 --zone="$ZONE" --command="
  pgrep -af k6 || echo 'k6 process has exited';
  ls -la ~/k6/results/endurance-run-gen1.json 2>/dev/null || echo 'report not written yet'
"
```

**What to actually watch for in the log** — k6's own periodic progress
output includes current VU count and iteration rate; the things that
indicate trouble:
- `dropped_iterations` climbing — generator (this VM) can't keep up; check
  CPU with the command above
- Rising `http_req_failed` rate — target-side errors, not a generator
  problem
- A jump in `http_req_duration` avg without a TPS drop — target is slowing
  down but still keeping up

## 8. After the run — collect and merge results

Do this from Cloud Shell once all 4 VMs show a finished process (§7):

```bash
mkdir -p ~/results
for m in vm-gen1 vm-gen2 vm-gen3 vm-gen4; do
  MID="${m#vm-}"
  gcloud compute scp "$m:~/k6/results/endurance-run-${MID}.json" ~/results/ --zone="$ZONE"
done

node merge-report.js --dir ~/results --name endurance-run
```

This produces one combined `.html`/`.json`: exact summed counters
(requests, pass/fail, cache hit/miss) across all 4 VMs, and weighted-average
latency percentiles (flagged as approximate — percentiles from separate
processes can't be merged exactly, only counters can).

## 9. Recommended order of operations, end to end

1. `smoke` on one VM — confirm script + target work (seconds).
2. `stress` on one representative VM — get real p95 latency and find the
   per-VM TPS ceiling (1h).
3. Edit the VU placeholders in `RUN_PROFILES` (§5) using that p95.
4. `load` on one VM at your normal expected TPS — baseline (1h).
5. `spike` on one VM — check recovery behavior (~2h).
6. `endurance` across all VMs you're actually using, launched together via
   §6, monitored via §7, collected and merged via §8 (6h).
